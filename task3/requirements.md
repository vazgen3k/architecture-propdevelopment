| Группа требований            | Требование                                                                  |
|------------------------------|-----------------------------------------------------------------------------|
| Безопасность канала          | Все интеграции выполняются только по TLS                                    |
| Идентификация систем         | Используется взаимная аутентификация систем, желательно mTLS                |
| Аутентификация сервисов      | Для server-to-server вызовов применяется OAuth 2.0 Client Credentials       |
| Аутентификация пользователя  | Пользователь аутентифицируется только во внутреннем контуре PropDevelopment |
| Авторизация                  | Реализуется проверка прав по ролям и по объектам доступа                    |
| Минимальные привилегии       | Каждой интеграции и каждому сервису выдаются только необходимые права       |
| Изоляция данных              | Исключается доступ к данным других ЖК, подъездов, квартир и автомобилей     |
| Минимизация данных           | Передаются только необходимые для операции данные                           |
| Защита чувствительных данных | Биометрия и номера автомобилей защищаются как чувствительные данные         |
| Журналирование               | Все вызовы API и критичные действия фиксируются в журналах                  |
| Контроль целостности         | Реализуется защита от подмены и повторного воспроизведения команд           |
| Контроль источников          | Запросы принимаются только от доверенных сервисов и адресов                 |
| Отказоустойчивость           | Настраиваются тайм-ауты, retry, безопасный отказ и обработка ошибок         |
| Архитектура интеграции       | Мобильное приложение не обращается к внешней платформе напрямую             |
| Интеграционный слой          | Все обращения проходят через внутренний слой PropDevelopment                |
| Обмен событиями              | Для событий используется webhook с подписью или брокер сообщений            |
| Аудит                        | Для каждой операции используется trace-id и ведётся сквозная трассировка    |
